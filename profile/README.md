## Starting a Laravel Pint Setup

Prerequisites: A Laravel or PHP project managed with Composer, a working PHP runtime, and terminal access for running formatting commands.

1.  **Install the Tool:** Use Laravel Pint install guidance from the project docs or add Laravel Pint composer support through the dependency setup used by your repository.
2.  **Create Configuration:** Add a Laravel Pint config file when the default preset needs project-specific paths, exclusions, or Laravel Pint rules.
3.  **Run Formatting Locally:** Execute the Laravel Pint command to apply Laravel Pint format behavior, or use Laravel Pint test mode to check style without changing files.
4.  **Connect Automation:** Add Laravel Pint ci checks with Laravel Pint GitHub Actions so every pull request can verify formatting before review.

## Fixing Common Formatting Friction

- Laravel Pint command not found? Confirm the Composer dependency is installed and run the executable from the vendor binary path or a Composer script.
- Formatting changes too many files? Review Laravel Pint config exclusions, then rerun Laravel Pint test before applying broad Laravel Pint fix changes.
- CI passes locally but fails remotely? Compare PHP versions, Composer installation steps, and Laravel Pint ci commands used by Laravel Pint GitHub Actions.
- Editor tasks do nothing? Check Laravel Pint vscode task paths, workspace settings, and whether the project script calls the same php pint command used in the terminal.
